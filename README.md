# EdenNetwork

**Eden RealID research and development within the Light of Hope ecosystem.**

EdenNetwork is building a shared identity and community-governance foundation intended for Light of Hope, EdenNetwork, and PwnZ, with privacy-preserving participation and the long-term goal of one unique-human credential per person.

**Current status:** The public GitHub repository is being established. This repository does **not** currently implement verified one-human-one-account recognition, live ZK enrollment, biometric verification, or production DAO voting. Existing website deployments are separate until their actual source and Git integration are reviewed.

## Principles
- Public participation should not require posting a legal name, biometric template, wallet identity, or real-world account linkage.
- Existing account authentication remains distinct from future human-uniqueness credential issuance.
- Public timestamp or commitment records must not identify a member or which profile they own.
- Hope Labs uses synthetic-only security and identity research. ANNEAL is never an authorization authority.
- Wallet, Pi marketplace, governance, and other integrations require separately validated, optional pathways.
