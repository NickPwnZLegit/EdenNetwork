# Security policy | EdenNetwork

EdenNetwork's public repository is for reviewed, non-sensitive source and documentation. **No real human-uniqueness enrollment, biometric scanning, proof-of-personhood determination, payment, or live DAO authorization is offered by this repository.**

## Reporting

Please **do not post vulnerabilities, private logs, personal data, secrets, or biometric information in public issues or pull requests**. Use GitHub private vulnerability reporting if it is available for this repository, or contact the maintainers through a privately agreed channel. Do not assume that a channel is enabled until confirmed.

## Confidentiality boundaries

Never commit member/account records, credential mappings, real biometric inputs or templates, recovery tokens, issuer keys, Firebase service accounts, production credentials, wallet keys, raw internal security logs, or private Hope Labs research.

Synthetic fixtures may be public only after review for accidental identifiers and secret-like values. External providers and ANNEAL output never determine identity, access, votes, payouts, wallet control, or production launch decisions.

## Release controls

Public code or a passing CI build is not an authorization to deploy. Production changes require source provenance, code review, tested backend authorization and data rules, browser/device QA, privacy/security review where applicable, confirmed environment scope, and explicit approval of the exact release commit.
